# 完整上抛过程的数据来源

本目录保存用于补齐视频的完整状态序列。原视频只展示释放后的飞行，因此补录了同一配置下释放前的夹持、抬升、摆臂与挥臂动作。

对四档逐项比较：从准备阶段到释放时刻，物理 CSV 的时间、物体位置/速度和六轴关节位置/速度全部一致，最大误差为 0；离手第一帧的关节位置/速度、手指角、物体位置/速度和物体姿态也完全一致。核对结果与源文件校验值在 `manifest.json`。

视频采用“经一致性核对的释放前补录 + 原通过审计的飞行与接回状态”连续渲染，界面和播放页均标明分段来源。没有用示意姿态代替缺失的物体姿态，也没有改变接回控制或重新定义成功条件。

补录时发现，新的规划耗时会影响部分接回结果；50.2 cm 档的新增接回尝试没有通过稳定保持要求。因此没有把补录称为新的完整成功验证，也没有更新原 12 次验证的成功率。所有补录尝试的审计保存在相邻的 `vertical_height_catch_20261021_full_motion/audit_index.json`；完整视频的飞行与接回段来自原来的成功记录。
