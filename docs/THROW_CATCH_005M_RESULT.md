# 0.05 米抛接技能实验结果

实验于 2026-10-19 开始，2026-10-20 完成（Asia/Shanghai）；目录日期采用开始日。

已在 PyBullet xArm6 仿真中完成“抓起 → 自由飞行升高至少 0.05 米 → 下降接住 → 平稳放地”。复用用户指定库中的 `grasp_without_lift_v1`，新技能保存为 `assets/skills/throw_005m_catch_ground.json`。

## 实测验证

| 试验 | 故障 | 自由飞行相对升高 | 下降接球相对速度 | 放地后位移 | 结果 |
|---|---|---:|---:|---:|---|
| 学习 attempt_01 | 无 | 0.054878 m | 0.946320 m/s | 0.028063 mm | 完整通过 |
| validation_01 | 无 | 0.054878 m | 0.946320 m/s | 0.028063 mm | 完整通过 |
| validation_02 | 低夹持力 | 0.055100 m | 0.946158 m/s | 0.028022 mm | 检测未抬升并恢复后完整通过 |
| validation_03 | 无 | 0.054878 m | 0.946320 m/s | 0.028063 mm | 完整通过 |

正常试验释放中心高度 0.326223 m，顶点 0.381102 m；恢复试验为 0.328931 m → 0.384031 m。每次飞行均有 49 个无抓持约束、无环境接触的物理步，步长 1/240 秒。接球前实际观测到上升、顶点与下降；捕获时物体位于腕部下方至少 0.10 m。

放地前先通过腕部 IK 缓慢扶正，然后反馈下降到真实地面支撑，以低于 0.000085 m/s 的实测速度释放，观察至少两秒。最终线速度约 0.0000124 m/s，角速度约 0.0000592 rad/s。关节实测速度最大比值 1.008909，满足预先设定的 1.05 数值容差。

## 过程中的事件与修正

1. 检查发现旧 0.5 米入口残留 10 米提示词、0.70 米桌面阻碍放地；本次建立明确的 0.05 米独立入口，使用地面可达场景。
2. 首次校准命令的内联 JSON 被 Windows 批处理剥离引号，物理试验前解析失败；改为 JSON 参数文件输入。
3. 校准 01 已抛高 0.054878 m 并接住，但下降反馈过慢、步数耗尽；调整每轮位移与跟踪时长。
4. 校准 02 成功扶正，但物体在手掌附近导致夹爪先碰地；收紧接球几何，要求中心位于腕部下方至少 0.10 m，保留放地净空。
5. 将两次失败测量、来源技能和动作边界发送给大模型。模型选择参数，试验完整通过；再次反馈实测数据后冻结参数。
6. 三次独立验证全部通过，包括一次低夹持力故障；模型收到全部结果并审阅。
7. 从已保存技能文件重新加载参数，独立执行并录制真实仿真相机画面。视频中自由飞行片段慢放四倍，其余按仿真时间播放。
8. 终检发现无状态 API 提示词中“首次必须 try”的歧义，明确空报告规则与正式验证计数后补充审阅，大模型返回 `accept`。本地技能验证始终依据实际物理测量。
